# Explainer Studio

مصنع فيديوهات Explainer متخصص، يعمل بواجهة عربية مناسبة للهاتف، ويتيح إنتاج فيديوهات تفسيرية شبه آلية من الفكرة إلى ملف MP4.

## مبادئ المشروع

- التطبيق موجّه أولًا للهاتف، بواجهة عربية RTL قابلة للتثبيت كتطبيق ويب تقدمي (PWA).
- المستخدم يقدّم الفكرة؛ ويتولى خط الإنتاج البحث، والسيناريو، وبناء المشاهد، والرسوم، والتحريك، والتعليق الصوتي، والتصدير، ومراجعة الجودة.
- يجب أن يكون محرك الإنتاج قابلًا للتشغيل بأوامر منظّمة، لا عبر الواجهة المرئية فقط، حتى يستطيع وكيل الذكاء الاصطناعي إنشاء المشاريع وتشغيلها وفحص نتائجها.
- الهوية البصرية تعتمد الرسوم المتجهة، والخرائط، والمخططات، والأشكال، والطباعة الحركية، والانتقالات وزوايا الكاميرا.
- لا أشخاص، ولا حيوانات، ولا شخصيات حية. لا موسيقى؛ المسموح هو التعليق الصوتي والمؤثرات غير الموسيقية فقط.
- حفظ المشروع بصيغة بيانات مستقلة وقابلة لإعادة الفتح والتصدير.

## اتجاه التقنية المبدئي

- React + TypeScript + Vite للواجهة.
- Remotion Player للمعاينة ومحرك Remotion للتصيير البرمجي.
- SVG ومكوّنات React مرسومة بإطارات زمنية محددة للمشاهد والرسوم التفسيرية.
- FFmpeg للتجميع والتحقق من ملفات الفيديو والصوت.
- IndexedDB لحفظ المشاريع محليًا على الجهاز.
- PWA لتجربة تثبيت على Android.

## الحالة الحالية

**مرحلة التأسيس والبحث التقني.** لم يُدمج محرك تصدير نهائي ولم يُنتج ملف MP4 قابل للتسليم بعد. لن تُعلن أي ميزة على أنها مكتملة قبل تنفيذ اختبار فعلي لها.

## بوابة الجودة الأولى

1. مشروع تجريبي من عدة مشاهد.
2. معاينة متزامنة للصورة والصوت.
3. تعليق عربي، ونصوص عربية سليمة الاتجاه والتشكيل.
4. رسوم متحركة وزوم وانتقالات.
5. تصدير MP4 حقيقي بدقة 1080p.
6. فحص مدة الفيديو والدقة ومعدل الإطارات والمسارات الصوتية، ومراجعة لقطات من الناتج.
7. التحقق من خلو المشروع من الموسيقى والكائنات الحية.
