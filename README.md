# مرشد Godot | Godot Mentor

طبقة تعليم وإرشاد عربية فوق **محرك Godot الحقيقي**، وليست محركًا بديلًا.

**الفرع:** `godot-beginner` — **الأساس:** Godot 4.7.2-stable — **الحالة:** نموذج أولي 0.1.0

## ما يقدمه النموذج الحالي
- لوحة تعليم عربية داخل محرر Godot.
- **15 درسًا تفاعليًا**: العقد والمشاهد، GDScript، الحركة، الإشارات، مناطق التلامس، الواجهات، المؤقتات، التحريك، الحفظ والقراءة، المجموعات، تصحيح الأخطاء، وInputMap والتصدير.
- أسئلة تفاعلية مع تصحيح فوري، وتلميحات، وحفظ تقدم محلي.
- نسخ أمثلة GDScript، وقائمة مباشرة للانتقال بين الدروس.
- إنشاء مشهد تدريبي للحركة داخل المشروع بزر واحد.
- موارد Android عربية، وتعيين العربية وRTL كإعدادَي بداية في محرر Android فقط.
- CI يفحص المشروع، ويختبر التعديلات الأصلية، ويحاول بناء محرر ARM64. عند اكتمال البناء، يرفع ملف APK وحزمة مشروع الدروس كأثرَي تنزيل منفصلين.

## تشغيل الإضافة
1. على Android، استخرج `godot-mentor-project-4.7.2.zip` إلى مجلد في الهاتف.
2. افتح Godot Editor، واختر Import ثم المجلد الذي يحتوي على `project.godot`.
3. افتح المشروع؛ الإضافة مفعّلة افتراضيًا في إعدادات المشروع، وإن لم تظهر ففعّل Godot Mentor من Project Settings > Plugins.
4. افتح لوحة المرشد، واختر الدرس وأجب عن السؤال.
5. في درس الحركة أنشئ مشهد التدريب، ثم شغله داخل Godot.
6. ملف APK المخصص هو تطبيق المحرر نفسه، أما ZIP فهو مشروع الدروس الذي تفتحه داخله.

## حالة التنفيذ الصريحة
- **اجتاز:** تحميل مشروع Godot والإضافة عبر Headless editor على GitHub Actions.
- **اجتاز:** التحقق من مورد Android العربي مقابل أسماء الموارد الرسمية.
- **اجتاز:** تطبيق سكربت العربية وRTL مرتين على نسخة مؤقتة من مصدر Godot دون تكرار التعديل.
- **قيد التنفيذ:** بناء APK عبر SCons بعد تجهيز SDK وNDK وSwappy وتطبيق إعدادَي العربية وRTL. حزمة المشروع تُنتج منفصلة عن APK لأن الإضافة التعليمية تعمل كمشروع Godot يفتح داخل المحرر.
- **لم يكتمل:** APK ناجح أو اختبار تثبيت فعلي على هاتف.
- **لم يكتمل:** مساعد AI متصل بالمشروع؛ توجد وثيقة معمارية فقط.
- **لم يكتمل:** إعادة تصميم واجهة المحرر كاملة لتلائم الهاتف.

## بنية المشروع
- `addons/godot_mentor/`: إضافة الدروس.
- `docs/`: تشريح المحرك، استراتيجية Android، المنهج ومعمارية المساعد.
- `patches/godot-4.7.2/`: تعديلاتنا المنفصلة على المصدر الرسمي.
- `.github/workflows/`: فحوصات وبناء Android.
