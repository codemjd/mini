# مرشد Godot | Godot Mentor

طبقة تعليم وإرشاد عربية فوق **محرك Godot الحقيقي 4.7.2-stable**، وليست محركًا بديلًا.

**الهدف:** محرر Godot مناسب للمبتدئ على Android، مع أدوات تعليمية عملية. **لا يتضمن المشروع مساعد ذكاء اصطناعي أو اتصالًا بنماذج خارجية.**

## المحتوى الحالي
- 20 درسًا تفاعليًا تغطي أساسيات 2D و3D.
- أسئلة مع تصحيح فوري، تلميحات، وحفظ تقدم محلي.
- إنشاء مشهد تدريبي للحركة داخل المشروع.
- لوحة أدوات مدمجة في Dock واحد لتقليل ازدحام واجهة المحرر.
- وضع مبتدئ يقدّم الشرح المختصر، ووضع موسّع يعرض التفاصيل التقنية.
- دليل عربي لعناصر Godot الشائعة: Node وNode2D وSprite2D وCharacterBody2D وArea2D وControl وعناصر أخرى.
- مكتبة من 8 قوالب GDScript قابلة للمعاينة والنسخ: حركة لاعب، صحة، التقاط عملة، مقذوف، تتبع هدف بسلوك حتمي، واجهة نقاط، مؤقت، وزر بدء.
- مختبر بصري معزول لتجربة المقياس والدوران ورؤية النتيجة مباشرة. لا يغيّر ملفات المشروع تلقائيًا.

## اتجاه تطوير Android
- العربية وRTL كإعدادَي بداية في محرر Android فقط.
- هوية تطبيق مستقلة: مرشد Godot.
- إعداد بناء ARM64 عبر GitHub Actions باستخدام Godot 4.7.2 وSDK/NDK مثبتين.
- نهدف إلى تقليل ازدحام الواجهة على الهاتف، لكن لا ندّعي أن كل واجهة Godot الأصلية أعيد تصميمها بعد.

## تشغيل الإضافة
1. استخرج حزمة المشروع ZIP إلى مجلد في الهاتف.
2. افتح Godot Editor واختر Import للمجلد الذي يحتوي على `project.godot`.
3. افتح مشروع مرشد Godot.
4. استخدم تبويب الدروس للتعلم، وتبويب الأدوات لشرح العناصر والقوالب والمختبر.

## حالة التنفيذ الصريحة
- **اجتاز:** تحميل مشروع Godot والإضافة عبر Headless editor على GitHub Actions.
- **اجتاز:** التحقق من 20 درسًا، وموارد Android العربية، وتعديلات اللغة وRTL وهوية التطبيق.
- **اجتاز:** فحص الإضافة الحالية على Godot 4.7.2 Headless.
- **قيد التنفيذ:** بناء محرر Android ARM64 من المصدر عبر SCons.
- **متاح كأثر بناء منفصل:** حزمة مشروع الدروس والإضافة ZIP؛ وهي ليست APK.
- **لم يكتمل بعد:** APK مخصص ناجح واختبار تثبيته وتشغيله على هاتف حقيقي.
- **لم يكتمل بعد:** إعادة تصميم جميع قوائم وأدوات Godot الأصلية لتجربة هاتف كاملة.
