# مرشد Godot | Godot Mentor

طبقة تعليم وإرشاد عربية فوق **محرك Godot الحقيقي**، وليست محركًا بديلًا أو محاكاة لواجهة Godot.

**الفرع:** `godot-beginner`  
**خط الأساس:** Godot 4.7.2-stable  
**الحالة:** نموذج أولي قابل للتطوير — 0.1.0

## الفكرة

نحتفظ بقدرات Godot الأصلية، ونضيف تجربة مناسبة للمبتدئ:

- مرشد داخل محرر Godot على شكل لوحة تعليمية.
- دروس قصيرة متدرجة، وأسئلة تفاعلية، وتلميحات.
- حفظ تقدم الدروس محليًا.
- نسخ أمثلة GDScript بنقرة واحدة.
- إنشاء مشهد تدريبي حقيقي من داخل المحرر في درس الحركة.
- أساس معماري لتطوير واجهة Android وتحسينها لاحقًا.

## تجربة النموذج الحالي

1. افتح هذا المجلد كمشروع باستخدام Godot **4.7.2-stable**.
2. افتح Project > Project Settings > Plugins، ثم فعّل **Godot Mentor | مرشد Godot** إذا لم يكن مفعّلًا تلقائيًا.
3. ستظهر لوحة «مرشد Godot» داخل المحرر.
4. انتقل بين الدروس، أجب عن الأسئلة، انسخ الكود، وعلّم التطبيق بعد تنفيذه.
5. في درس الحركة اضغط «أنشئ مشهد التدريب» لإنشاء مشهد CharacterBody2D وسكربت حركة داخل مجلد lessons.

## الدروس الموجودة في النموذج الأولي

1. العقدة Node.
2. المشهد Scene وشجرة العقد.
3. أول سكربت GDScript.
4. حركة CharacterBody2D وإنشاء مشهد تدريبي.
5. أساسيات تصدير ألعاب Android.

## ما لم ندّعِ اكتماله بعد

- هذه النسخة إضافة EditorPlugin تعمل فوق Godot 4.7.2؛ لم نعدّل حتى الآن ملفات C++ أو Kotlin في مصدر المحرك.
- لم يُنتج APK مخصص للمحرر بعد.
- لم يُختبر الإضافة على هاتف Android فعلي.
- لم يُدمج اتصال بمساعد ذكاء اصطناعي أو API خارجي بعد.
- لم تُستكمل بعد واجهة الهاتف العربية الكاملة أو مكتبة الدروس الموسعة.

هذه حدود مقصودة للمرحلة الأولى: نثبت طريقة إضافة الدروس وتشغيلها فوق Godot قبل إجراء تغييرات أعمق في المحرر الأصلي.

## بنية المشروع

- `addons/godot_mentor/`: إضافة المحرر التعليمية.
- `lessons/`: ملفات التدريب التي ينشئها المرشد.
- `docs/ENGINE_RECONNAISSANCE.md`: تشريح مبدئي للمصدر الرسمي ونقاط التعديل.
- `docs/ANDROID_STRATEGY.md`: استراتيجية Android والأداء.
- `docs/LESSON_CURRICULUM.md`: خطة توسعة المنهج التفاعلي.
- `.github/workflows/validate-godot.yml`: فحص المشروع بواسطة Godot في GitHub Actions.

## الأساس والترخيص

Godot Engine مشروع مفتوح المصدر مرخّص MIT. هذا المستودع لا يضم نسخة من مصدر Godot؛ بل يضيف ملفات مشروع وإضافة تعليمية تعمل فوقه. راجع وثائق Godot الرسمية قبل بناء نسخة مشتقة من المحرر أو توزيعها.

- المصدر: https://github.com/godotengine/godot
- توثيق المحرر على Android: https://docs.godotengine.org/en/4.7/tutorials/editor/using_the_android_editor.html
- بناء محرر Android من المصدر: https://docs.godotengine.org/en/stable/engine_details/development/compiling/compiling_for_android.html
