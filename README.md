# ورشة الشرارات Mini

محرر عربي مبسط لصناعة مشاهد ألعاب 2D من الهاتف والمتصفح، مبني باستخدام Phaser وTypeScript وVite.

## جرّب النسخة التجريبية

https://codemjd.github.io/mini/

## الموجود حاليًا — الإصدار 0.3

- محرر مشهد بأبعاد 800×450 وخمسة أنواع من العناصر.
- رسومات كرتونية محسّنة للساحة والشخصيات والعناصر.
- معاينة لعب بسيطة مع حركة بالأسهم أو WASD وأزرار لمس وجمع العملات.
- استعادة المشهد بعد إيقاف المعاينة.
- تعديل الموقع والاسم واللون والحجم لجميع العناصر.
- خصائص صحة وسرعة وضرر للشخصيات والأعداء.
- التراجع والإعادة، قفل العناصر، ترتيب الطبقات، ومحاذاة الشبكة.
- تركيبات جاهزة لإضافة مجموعات عناصر بسرعة.
- حفظ محلي، استيراد JSON، وتصدير JSON.

## تشغيل التطوير

```bash
npm install
npm run dev
```

## الاختبار والبناء

```bash
npm run typecheck
npm run build
npm run test:e2e
```

## حدود النسخة الحالية

المعاينة نموذج لعب أولي وليست محركًا كاملًا. لا يوجد بعد محرر أحداث مرئي أو نظام تصادم وقتال متكامل أو إدارة مشاهد متعددة أو تصدير HTML5/ZIP أو APK. ملف JSON هو بيانات مشروع، وليس تطبيقًا قابلًا للتثبيت.

راجع [خارطة الطريق وخطة الجودة](docs/ROADMAP-AND-TEST-PLAN.md) لمعرفة ما أُنجز وما يأتي لاحقًا.
