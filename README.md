# مرشد Godot | Godot Mentor

طبقة تعليم وإرشاد عربية فوق **محرك Godot الحقيقي**، وليست محركًا بديلًا.

**الفرع:** `godot-beginner` — **الأساس:** Godot 4.7.2-stable — **الحالة:** نموذج أولي 0.1.0

## ما يقدمه النموذج الحالي
- لوحة تعليم عربية داخل محرر Godot.
- خمسة دروس: العقد، المشاهد، GDScript، حركة CharacterBody2D، وتصدير Android.
- أسئلة تفاعلية مع تصحيح فوري، وتلميحات، وحفظ تقدم محلي.
- نسخ أمثلة GDScript.
- إنشاء مشهد تدريبي للحركة داخل المشروع بزر واحد.
- موارد Android عربية، وسكربت يجعل العربية لغة البداية في محرر Android فقط.
- CI يفحص المشروع، ويختبر التعديلات الأصلية، ويحاول بناء محرر ARM64.

## تشغيل الإضافة
1. افتح المشروع في Godot 4.7.2-stable.
2. افتح Project > Project Settings > Plugins وفعّل Godot Mentor إذا لم يعمل تلقائيًا.
3. افتح لوحة المرشد، واختر الدرس وأجب عن السؤال.
4. في درس الحركة أنشئ مشهد التدريب، ثم شغله داخل Godot.

## حالة التنفيذ الصريحة
- **اجتاز:** تحميل مشروع Godot والإضافة عبر Headless editor على GitHub Actions.
- **اجتاز:** فحص موارد XML العربية في المحاولة الأولى.
- **قيد الإصلاح:** بناء APK. تم تجهيز SDK وNDK، وتثبيت Swappy، لكن المحاولة الأخيرة كشفت عدم تطابق Patch C++ النصي مع المصدر. استبدلناه بسكربت Python يتحقق من السطر المستهدف ويعدله بأمان.
- **لم يكتمل:** APK ناجح أو اختبار تثبيت فعلي على هاتف.
- **لم يكتمل:** مساعد AI متصل بالمشروع؛ توجد وثيقة معمارية فقط.
- **لم يكتمل:** إعادة تصميم واجهة المحرر كاملة لتلائم الهاتف.

## بنية المشروع
- `addons/godot_mentor/`: إضافة الدروس.
- `docs/`: تشريح المحرك، استراتيجية Android، المنهج ومعمارية المساعد.
- `patches/godot-4.7.2/`: تعديلاتنا المنفصلة على المصدر الرسمي.
- `.github/workflows/`: فحوصات وبناء Android.
