# Explainer Studio

مصنع فيديوهات Explainer متخصص، بواجهة عربية RTL مناسبة للهاتف. الهدف أن يحوّل وكيل الذكاء الاصطناعي الفكرة إلى مشروع مشاهد ثم فيديو تفسيري مكتمل، مع تدخل يدوي محدود.

**معاينة الويب:** https://codemjd.github.io/mini/  
**المستودع:** https://github.com/codemjd/mini

## فلسفة المنتج

- المستخدم يقدّم الفكرة؛ وخط الإنتاج يتولى البحث، والسيناريو، وبناء المشاهد، والرسوم، والتحريك، والتعليق الصوتي، والتصدير، ومراجعة الجودة.
- يجب أن يكون خط الإنتاج قابلًا للتحكم بأوامر منظمة من وكيل آلي، لا عبر النقر على الواجهة فقط.
- الهوية البصرية تعتمد الرسوم المتجهة، والخرائط، والمخططات، والأشكال، والطباعة الحركية، والانتقالات والزوم.
- لا أشخاص، ولا حيوانات، ولا شخصيات حية. لا موسيقى؛ المسموح هو التعليق الصوتي والمؤثرات غير الموسيقية فقط.
- تُحفظ المشاريع محليًا افتراضيًا. ملفات الصوت أصول مستقلة في IndexedDB، وتُضمّن في حزمة JSON عند التصدير.

## ما يعمل في النسخة 0.2

- لوحة مشاريع وواجهة استوديو عربية متجاوبة.
- إنشاء مشروع وفتح مشروع محفوظ.
- إضافة المشاهد وتحرير عناوينها ومددها ونصوصها وألوان خلفياتها.
- حذف المشاهد وإعادة ترتيبها.
- معاينة متحركة فعلية للمشهد الحالي عبر Remotion Player، مع تخطيطات متخصصة للاقتباس والمقارنة ومسارات المراحل، وانتقالات تداخلية متحركة بين المشاهد.
- خط زمني أولي وخصائص للمشهد.
- حفظ محلي عبر IndexedDB مع بديل localStorage.
- استيراد المشروع وتصديره بصيغة JSON ذات إصدار، مع فحص بنية البيانات قبل الاستيراد.
- واجهة أوامر محلية typed للوكيل الآلي: `window.explainerStudio.execute(command)`، مع تصيير MP4 وتنزيله عبر `render` و`renderAndDownload` بعد موافقة الخصوصية.
- سياسة محتوى صريحة داخل نموذج المشروع تمنع تفعيل الشخصيات الحية والموسيقى، مع ترحيل آمن للمشاريع القديمة.
- مسار تصيير MP4 تجريبي محلي باستخدام WebCodecs، مع فحص توافق المتصفح.
- إرفاق تعليق صوتي لكل مشهد بصيغتي MP3 وWAV، بحد أقصى 30 ميغابايت للملف.
- حفظ ملفات الصوت الفعلية في IndexedDB مع إنشاء روابط مؤقتة للمعاينة والتصيير، دون حفظ روابط Blob في بيانات المشروع.
- معاينة التعليق الصوتي داخل Player على خط زمن المشهد، وتهيئة تصدير MP4 لاستخدام AAC عند وجود صوت.
- حزمة مشروع JSON ذات إصدار تتضمن أصول الصوت Base64، مع حدود للحجم والتحقق من ارتباط كل ملف بمشهده عند الاستيراد.
- تنظيف ملفات الصوت عند حذف المشهد أو المشروع، مع إبقاء المشاريع القديمة التي لا تتضمن مسارًا صوتيًا متوافقة.
- PWA manifest وService Worker لهيكل العمل دون اتصال.
- اختبارات تحقق آلية لهيكل المشروع، وفحص TypeScript وبناء إنتاجي، ونشر معاينة عبر GitHub Pages.
- أُضيف فحص CI لمسار AAC بعينة WAV صامتة؛ هذا يختبر muxing فقط ولا يثبت جودة التعليق العربي أو مزامنته السمعية.
- اختبار تصيير حقيقي سابق على GitHub Actions: فيديو عربي تجريبي 12 ثانية، 1920×1080، H.264، 30 FPS، تم فحصه بـ FFprobe. أضيف اختبار تصيير أطول مع فحص آلي للمدة والدقة والترميز؛ فشل التحقق الأول بسبب توقع مدة غير متوافقة مع تداخل المشاهد، وتم إصلاح شرط المدة وإطلاق إعادة الاختبار. لا يُعد الفيديو الجديد متحققًا حتى ينجح الفحص ويرتفع artifact.
- نتائج الاختبار التفصيلية: `docs/TEST_RESULTS.md`.

## حدود تصيير MP4 الحالية

- التصدير المحلي محدود حاليًا إلى 90 ثانية، وبحد أقصى 1280×720 (720p)، ويحتاج متصفحًا يدعم WebCodecs وترميز H.264.
- يمكن إرفاق تعليق صوتي جاهز لكل مشهد؛ توليد الكلام من النص (TTS) لم يُدمج بعد. لا موسيقى.
- هذه حدود حماية أولية وليست وعدًا بأن كل هاتف يستطيع التصيير؛ لم نختبر التصدير المحلي على هاتف Android فعلي بعد.
- مسار Remotion CLI على GitHub Actions أنتج ملف MP4 حقيقيًا وفُحص بنجاح: H.264، 1920×1080، 30 FPS، 12 ثانية.
- قبل أول تصيير محلي تظهر موافقة خصوصية؛ Remotion يرسل بيانات تشغيل محدودة (IP ونطاق الموقع ونوع العملية وحالتها)، ولا يرسل ملف الفيديو أو محتوى المشروع.
- تصيير 1080p وثماني دقائق، ونموذج TTS عربي، واختبار Android الفعلي، ومراجعة جودة الصوت ما زالت مراحل منفصلة لم تكتمل.

## ما لم يكتمل بعد

- لم نراجع الناتج البصري من تصيير MP4 داخل متصفح فعلي؛ اختبار MP4 الناجح الحالي جرى على خادم CI.
- لم يتم اختبار دعم العربية واتجاه RTL في ملف الفيديو الناتج.
- لا يوجد عامل تصيير طويل المدة متصل بالتطبيق.
- لا يوجد مزود TTS موصول بعد؛ المتاح إرفاق ملف صوتي جاهز لكل مشهد.
- لم يتم التحقق من التثبيت وإعادة فتح التطبيق على هاتف Android فعلي.
- لا يوجد تسجيل دخول أو مزامنة سحابية؛ بيانات المشاريع محلية على المتصفح.
- أضيفت اختبارات آلية أولية للتحقق من إصدار schema والحقول والمدد والمعرّفات والحدود.

## التقنية المثبتة

- React 19.3.1
- TypeScript 5.9.3
- Vite 8.3.8
- Remotion و@remotion/player و@remotion/web-renderer 4.0.547
- IndexedDB وPWA Service Worker

تُثبت حزم Remotion على الإصدار نفسه لتجنب تعارض الإصدارات. راجع `docs/ARABIC_VOICE_AND_RENDERING.md` لبحث التعليق الصوتي العربي، و`docs/VOICE_PIPELINE_IMPLEMENTATION.md` لمواصفات خط التعليق الصوتي وحفظ أصول WAV واختبارات Android، و`docs/RESEARCH.md` للترخيص والقيود ومصادر البحث، و`docs/ARCHITECTURE.md` لتصميم النظام، و`docs/AGENT_API.md` لأوامر الوكيل، و`docs/TEST_RESULTS.md` لنتائج التحقق الفعلية.

## بوابة جودة التصدير

لا يعلن أن التصدير مكتمل للإنتاج قبل إنتاج ملف MP4 فعلي والتحقق من:
1. صلاحية الملف ومدة الفيديو والدقة ومعدل الإطارات.
2. وجود الصوت ومزامنته وسلامة نطقه.
3. عدم وجود موسيقى أو كائنات حية.
4. سلامة النص العربي والتكوين البصري.
5. مراجعة إطارات من البداية والوسط والنهاية.

## الخصوصية

المستودع عام، لذلك يحتوي على الكود والوثائق العامة فقط. لا ترفع إليه سيناريوهات خاصة أو ملفات فيديو شخصية أو مفاتيح خدمات. بيانات المشاريع في النسخة الحالية تبقى في تخزين المتصفح المحلي ولا تتم مزامنتها تلقائيًا إلى خادم. عند الموافقة على التصيير المحلي، تُرسل إلى Remotion بيانات القياس المذكورة أعلاه فقط، لا محتوى المشروع أو الفيديو.
