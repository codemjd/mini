# مرشد Godot | Godot Mentor

طبقة تعليم وإرشاد عربية فوق **محرك Godot الحقيقي**، وليست محركًا بديلًا أو محاكاة لواجهة Godot.

**الفرع:** `godot-beginner`  
**خط الأساس:** Godot 4.7.2-stable  
**الحالة:** نموذج أولي قابل للتطوير — 0.1.0

## الفكرة

نحتفظ بقدرات Godot الأصلية، ونضيف تجربة مناسبة للمبتدئ:

- مرشد داخل محرر Godot على شكل لوحة تعليمية.
- دروس قصيرة متدرجة، وأسئلة تفاعلية، وتلميحات.
- حفظ تقدم الدروس محليًا.
- نسخ أمثلة GDScript بنقرة واحدة.
- إنشاء مشهد تدريبي حقيقي من داخل المحرر.
- الاستفادة من ترجمة Godot العربية الحالية وتفعيلها افتراضيًا في بناء Android المخصص.
- موارد عربية أصلية لقوائم Android الخاصة بالمحرر.
- سير عمل آلي لتجميع محرر Android ARM64 من مصدر Godot المثبّت.

## تجربة إضافة الدروس

1. افتح هذا المجلد كمشروع باستخدام Godot **4.7.2-stable**.
2. افتح Project > Project Settings > Plugins، ثم فعّل **Godot Mentor | مرشد Godot** إذا لم يكن مفعّلًا تلقائيًا.
3. ستظهر لوحة «مرشد Godot» داخل المحرر.
4. انتقل بين الدروس، أجب عن الأسئلة، افتح التلميحات، وانسخ أمثلة GDScript.
5. في درس الحركة اضغط «أنشئ مشهد التدريب» لإنشاء مشهد CharacterBody2D وسكربت حركة داخل مجلد lessons.

## الدروس الموجودة في النموذج الأولي

1. العقدة Node.
2. المشهد Scene وشجرة العقد.
3. أول سكربت GDScript.
4. حركة CharacterBody2D وإنشاء مشهد تدريبي.
5. أساسيات تصدير ألعاب Android.

## ما اكتمل وما لم يكتمل

- **اكتمل:** إضافة محرر أولية تحتوي على خمسة دروس تفاعلية.
- **اكتمل:** حفظ تقدم الدروس محليًا، وتلميحات، وأسئلة تصحيح فوري، ونسخ أمثلة.
- **اكتمل:** مشهد حركة تدريبي يُنشأ من داخل الإضافة.
- **اكتمل:** موارد Android عربية، وPatch يضبط لغة المحرر الافتراضية إلى العربية في بناء Android.
- **اجتاز:** فحص GitHub Actions فتح مشروع Godot 4.7.2 وتحميل الإضافة، وفحص XML لموارد Android.
- **لم يكتمل:** بناء APK مخصص. محاولة البناء الأولى توقفت عند إعداد Android SDK بسبب حزمة `tools` القديمة التي أُزيلت. جرى تحديث Workflow إلى إعداد Android SDK الحالي، وجارٍ إعادة المحاولة.
- **لم يكتمل:** اختبار الإضافة على هاتف فعلي أو إثبات توافقها الكامل مع واجهة Android.
- **لم يكتمل:** مساعد AI متصل بالمشروع. توجد وثيقة معمارية فقط، ولا يُرسل أي مشروع إلى خادم خارجي.
- **لم يكتمل:** إعادة تصميم واجهة Godot الرئيسية لتكون صديقة للهاتف أو بناء منهج كامل.

## بنية المشروع

- `addons/godot_mentor/`: إضافة المحرر التعليمية.
- `docs/ENGINE_RECONNAISSANCE.md`: تشريح بنية المحرك ونقاط التعديل.
- `docs/ANDROID_STRATEGY.md`: استراتيجية Android والأداء.
- `docs/LESSON_CURRICULUM.md`: خريطة توسعة المنهج التفاعلي.
- `docs/AI_TUTOR_ARCHITECTURE.md`: معمارية المساعد الذكي.
- `patches/godot-4.7.2/`: تعديلات منفصلة تُطبّق على المصدر الرسمي.
- `.github/workflows/validate-godot.yml`: فحص المشروع والإضافة.
- `.github/workflows/build-android-editor.yml`: بناء محرر Android ARM64.
