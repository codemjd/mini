# ورشة الشرارات Mini — خارطة الطريق وخطة الجودة

آخر تحديث: 2026-11-13  
الإصدار المستهدف: 0.3

## ما أُنجز في الإصدار 0.3

- تحسين رسومات الساحة والشخصيات والعناصر بظلال وتفاصيل وألوان متناسقة.
- معاينة قابلة للإيقاف والاستعادة؛ جمع العملات مؤقت ولا يغيّر مشروع التحرير.
- تحكم باللمس على الهاتف ولوحة المفاتيح على الحاسوب.
- التراجع والإعادة حتى 60 خطوة.
- استيراد ملفات JSON مع فحص البنية وتقييد العدد والحجم وتنظيف القيم.
- تصدير JSON بالإصدار 2 مع استمرار دعم ملفات الإصدار 1.
- خصائص اللون والحجم لجميع أنواع العناصر، وخصائص الصحة والسرعة والضرر للشخصيات والأعداء.
- قفل العناصر لمنع سحبها، وتغيير ترتيب الطبقات، ومحاذاة اختيارية إلى شبكة 20 بكسل.
- ثلاث تركيبات جاهزة: طريق العملات، حاجز خشبي، وخصم للتحدي.
- اختبارات آلية للتراجع والإعادة والاستيراد والتركيبات والقفل والطبقات.

## الأولويات التالية

### P0 — ضمان الجودة وتجربة الهاتف
- فحص عرض 320 و360 و390 و430 و768 و1024 بكسل.
- اختبار أزرار اللمس على جهاز Android فعلي، وليس المحاكاة فقط.
- اختبار استيراد ملف تالف وكبير وملف يحتوي أنواعًا غير معروفة.
- اختبار الحفظ بعد الاستيراد وإعادة فتح الصفحة.
- إصلاح أي أخطاء في سجل المتصفح أو تحذيرات TypeScript.

**معيار القبول:** جميع اختبارات CI ناجحة، ولا يفقد المشروع بياناته عند التحرير أو الاستيراد أو المعاينة.

### P1 — محرر احترافي
- تراجع/إعادة أكثر دقة مع تجميع تغييرات السحب.
- تحديد متعدد، نسخ ولصق، ومحاذاة وتوزيع.
- خصائص متقدمة: الشفافية، الدوران، عرض/ارتفاع منفصلان، مرساة العنصر.
- حفظ تلقائي مع مؤشر واضح وحماية من تلف التخزين.
- مشاهد متعددة مع إدارة أسماء المشاهد وترتيبها.

**معيار القبول:** إدارة مشروع يتضمن عدة مشاهد وعشرات العناصر دون فقد أو بطء ملحوظ على الهاتف.

### P2 — مكتبة الأصول
- حزم شخصيات وبيئات ومؤثرات وأصوات مرخصة بوضوح.
- معاينة الأصول قبل إضافتها، وتصنيفات وبحث.
- دعم استيراد الصور والأصوات من الهاتف.
- تقليل حجم الأصول وتحميلها عند الحاجة.

**معيار القبول:** يمكن بناء مشهد جذاب من أصول مدمجة أو مستوردة دون الحاجة إلى كتابة كود.

### P3 — أنظمة اللعب
- محرر أحداث مرئي: عند البدء، عند الضغط، عند التصادم، عند جمع عنصر.
- تصادمات ومناطق تفعيل ومقاييس صحة.
- هجمات ومقذوفات وأعداء بسلوك أساسي.
- واجهة لعب قابلة للتخصيص ومراحل متعددة.
- قوالب ألعاب أولية قابلة للتعديل.

**معيار القبول:** إنتاج لعبة صغيرة مكتملة الهدف والنهاية، وليس مجرد مشهد يتحرك.

### P4 — التصدير
- حزمة HTML5 مستقلة قابلة للتشغيل دون المحرر.
- تصدير ZIP من المشروع.
- بناء Android APK عبر خدمة بناء سحابية بعد التحقق من متطلبات التوقيع والحزم.
- توثيق حدود التصدير ومتطلبات المتاجر.

**معيار القبول:** ملف HTML5 يعمل خارج الورشة؛ وAPK لا يُعلن جاهزًا إلا بعد بناء ناجح واختبار تثبيت فعلي.

## مصفوفة الاختبار

| المجال | الاختبار | معيار النجاح |
|---|---|---|
| البداية | فتح صفحة فارغة | يظهر المحرر والعناصر الافتراضية |
| إضافة العناصر | الأنواع الخمسة | عنصر صحيح في القائمة والمشهد |
| خصائص الشكل | تغيير اللون والحجم لكل نوع | يتغير الرسم والقيم فورًا |
| خصائص الشخصيات | صحة وسرعة وضرر | تظهر للشخصية والعدو فقط |
| التحريك | سحب وتعديل X/Y | قيم دقيقة ضمن حدود الساحة |
| الشبكة | تفعيل/تعطيل المحاذاة | تقريب الحركة إلى 20px عند التفعيل |
| القفل | قفل ثم محاولة السحب | يبقى العنصر ثابتًا |
| الطبقات | تقديم/إرجاع عنصر | يتغير ترتيب الرسم والقائمة |
| التاريخ | تراجع/إعادة | ترجع الإضافة والحذف والخصائص |
| التركيبات | إضافة طريق العملات | أربعة عناصر بعملية واحدة قابلة للتراجع |
| الاستيراد | ملف v1 وv2 | تحميل العناصر مع ترحيل آمن |
| الاستيراد السلبي | JSON تالف أو 500+ عنصر | رسالة خطأ دون انهيار |
| التصدير | تنزيل JSON | بنية version 2 سليمة |
| الحفظ | حفظ وإعادة تحميل | استعادة العناصر وخصائصها |
| المعاينة | حركة وجمع عملات | تفاعل صحيح مع عدم تعديل المشروع |
| الاستعادة | إيقاف المعاينة | عودة المشهد إلى حالته السابقة |
| الهاتف | أحجام 320–430px | الأزرار واللوحات لا تتداخل |
| المتانة | إعادة تحميل بعد تعديل | لا أخطاء ولا فقد غير متوقع |

## بوابات الإصدار

1. `npm run typecheck` ينجح.
2. `npm run build` ينتج `dist/index.html`.
3. `npm run test:e2e` ينجح على Chromium المكتبي والهاتف.
4. GitHub Pages ينشر نفس commit الذي اجتاز الاختبارات.
5. تجربة يدوية على هاتف Android للتحقق من اللمس والحجم والأداء.

## ما لا يزال غير مكتمل

هذه النسخة لا تحتوي بعد على محرر أحداث مرئي، أو نظام تصادم وقتال متكامل، أو إدارة مشاهد متعددة، أو حزمة HTML5 مستقلة، أو APK. ملف JSON يحفظ بيانات المشروع فقط. هذه أعمال المراحل التالية وليست ميزات منجزة.
