# ورشة الشرارات Mini — خارطة الطريق وخطة الجودة

آخر تحديث: 2026-11-14  
الإصدار المستهدف في هذا الفرع: **0.9.0 — أصول متجهية وتحريك وخلفيات وسلوكيات**

## الحالة المنجزة

### 0.8 — سير عمل المشاريع متعددة المشاهد
- نموذج مشروع v4 يدعم حتى 30 مشهدًا.
- إنشاء المشاهد وتبديلها ونسخها وإعادة تسميتها وحذفها مع حماية المشهد الأخير.
- حفظ عناصر وSpark Script مستقلة لكل مشهد.
- استيراد وتصدير المشروع الكامل، وترحيل صيغ v1/v2/v3.
- اختبارات عزل المشاهد والتبديل والنسخ والحذف وإعادة التحميل.

### 0.9 — مكتبة الأصول والتحريك والخلفيات والسلوك
- مكتبة مدمجة من 12 عنصرًا متجهيًا ضمن أربع فئات: شخصيات، أعداء، بيئة، مقتنيات.
- بحث نصي وتصنيف وإضافة مباشرة إلى المشهد.
- خمس حالات حركة لكل كائن: idle وfloat وpulse وbounce وwobble.
- سلوك عدو قابل للاختيار بين chase وguard.
- أربع خلفيات للمشهد: حديقة البلورات، أطلال الغروب، كهف الجليد، وكثبان الصحراء.
- تخزين motion وaiMode والخلفية داخل بيانات كل مشهد، وتطبيقها على المحرر ومعاينة melonJS.
- دعم ملفات المشاريع الأقدم التي لا تحتوي على هذه الخصائص بقيم افتراضية آمنة.
- اختبارات آلية للبحث عن الأصول وإضافتها، وحفظ الحركة والذكاء والخلفية وإعادة تحميلها.

## بوابات التحقق

لا يُعد أي بند ناجحًا لمجرد كتابة الكود أو الاختبار. يلزم التحقق من آخر commit تحديدًا.

| المرحلة | الفحص المطلوب | معيار النجاح |
|---|---|---|
| TypeScript | `npm run typecheck` | دون أخطاء |
| الإنتاج | `npm run build` | إنشاء dist صالح |
| المتصفح | `npm run test:e2e` | نجاح اختبارات سطح المكتب والهاتف |
| Android | سير عمل Android debug | APK Debug مرفوع وقابل للتنزيل |
| الجهاز الحقيقي | تثبيت واختبار Android فعلي | لمس، سحب، معاينة، حفظ وإعادة فتح دون فقد |
| النشر | Pages من نفس commit المختبر | الرابط المنشور يطابق commit |

## المرحلة التالية

### P0 — تثبيت الإصدار 0.9
- إصلاح أي إخفاق في اختبارات الأصول والحركة والخلفيات والسلوك.
- التأكد أن import/export يحافظ على motion وaiMode وbackground ويصحح القيم غير المعروفة بأمان.
- التأكد أن سلوك الحراسة لا يضيف FollowTarget، وسلوك المطاردة يضيفه.
- فحص APK الأحدث من حيث وجود artifact وحجمه وcommit المصدر.
- عدم الادعاء باختبار جهاز فعلي دون حصول ذلك.

### P1 — مكتبة أصول فنية فعلية
- دعم ملفات PNG وWebP وSprite Sheets من ملفات محلية مضمّنة.
- معاينات فعلية للأصول وصور مصغرة وبيانات مصدر وترخيص.
- إنشاء شخصيات ذات حالات خمول ومشي وهجوم وإصابة.
- استيراد أصول المستخدم مع فحص النوع والحجم والأبعاد.
- تجنب أي أصل مجهول الترخيص أو مجرد رابط خارجي لا يدخل المشروع.

### P2 — محرر الحركة
- Timeline مرئي مع مسارات موضع وحجم ودوران وشفافية.
- إطارات مفتاحية قابلة للإضافة والحذف والتحريك.
- تشغيل وإيقاف ومعاينة الإطارات ومعدل FPS.
- تخزين الحركة داخل كل مشهد وتصديرها مع المشروع.
- اختبارات للتسلسل الزمني وحدود الإطارات وملفات الحركة التالفة.

### P3 — محرر السلوك المرئي
- عقد وأحداث محددة: بدء اللعبة، لمس، تصادم، جمع، مؤقت.
- إجراءات: تحريك، تغيير صحة، تشغيل حركة، إظهار/إخفاء، إنهاء المرحلة.
- شروط بسيطة ومحدودة مع منع الحلقات غير المنضبطة.
- ربط واضح بين سلوك العنصر ومعاينة melonJS.
- عدم تنفيذ JavaScript اعتباطي أو `eval`.

### P4 — أدوات المحرر
- تحديد متعدد، نسخ/لصق، مجموعات، محاذاة وتوزيع.
- طبقات وأقفال أكثر وضوحًا.
- مناطق تصادم منفصلة عن الرسوم، ومحرر تصادم واضح.
- سجل تراجع وإعادة لكل عمليات التحرير.

### P5 — التصدير والتسليم
- حزمة HTML5 مستقلة.
- ZIP يتضمن المشروع والأصول المستخدمة.
- APK Debug للاختبار وRelease موقّع للنشر.
- فحص التثبيت والإقلاع والحفظ على Android فعلي.
- إبقاء مراحل البناء والتوقيع منفصلة وموثقة.

## قيود معلنة

- الأصول الـ12 الحالية رسوم متجهية برمجية؛ ليست حزمة شخصيات مرسومة كـSprite Sheets.
- الحركات الخمس تأثيرات تحويلية بسيطة، وليست محرر إطارات مفتاحية كاملًا.
- أنماط العدو الحالية مطاردة وحراسة؛ لا يوجد بعد تخطيط مسار أو ذكاء يتعلم أسلوب اللاعب.
- الخلفيات الأربعة تنويعات مرسومة برمجيًا وليست حزم خرائط/Tilemaps.
- Spark Script لغة أوامر محدودة وليست بيئة JavaScript عامة.
- اختبارات Chromium ومحاكاة الهاتف لا تثبت عمل التطبيق على هاتف Android فعلي.
- APK الناتج حاليًا Debug وليس APK Release موقّعًا.
